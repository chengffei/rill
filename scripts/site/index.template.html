What is Rill?Rill 是什么？

Rill is a free, open-source menu bar app for MacBook. It shows how many watts the charger delivers, how many the Mac uses, and how many go into or come out of the battery, live. It lists the apps using the most energy, watches memory pressure, and keeps 7 days of history. It reads only what macOS already reports, needs no special permissions, and goes online only when you check for updates. Rill 是免费开源的 MacBook 菜单栏工具。它实时显示充电器送进多少瓦、电脑用掉多少瓦、电池充入或放出多少瓦，列出最耗电的应用，盯着内存压力，并保留 7 天历史。它只读 macOS 本来就提供的数据，不需要特殊权限，只在你检查更新时联网。

安装Install

在终端里运行一行命令，脚本会校验签名后装进「应用程序」。 One line in Terminal. The script checks the signature and puts Rill in Applications. 

curl -fsSL https://raw.githubusercontent.com/chengffei/rill/main/install.sh | bash

也可以下载磁盘映像手动安装，步骤如下。 Or download the disk image and install it by hand:

拖进 ApplicationsDrag to Applications

打开下载的 dmg，把 Rill 拖到 Applications 文件夹。Open the disk image and drag Rill into the Applications folder.

先打开一次Open it once

双击 Rill，系统提示无法验证开发者，点「完成」。Double-click Rill. When macOS says it can’t verify the developer, click Done.

在设置里放行Allow in Settings

「系统设置 › 隐私与安全性」拉到底部，点「仍要打开」。In System Settings › Privacy & Security, scroll down and click Open Anyway.

需要 macOS 26 或更高、带电池的 Apple 芯片 Mac。菜单栏图标没出现时，可能被菜单栏管理工具收起了。 Requires macOS 26 or later on an Apple silicon Mac with a battery. If the icon doesn’t appear, a menu bar manager may have hidden it.

常见问题FAQ

安装和使用中最常被问到的几件事。Common questions about installing and using Rill.

How can I see how many watts my MacBook is using?怎么看 MacBook 正在用多少瓦？

Install Rill. The menu bar shows live watts, and the panel splits them into charger input, battery charge or drain, and what the Mac itself uses, updated every 2 seconds.装上 Rill。菜单栏直接显示实时瓦数，面板把它拆成充电器输入、电池充放电和电脑本身的用电，每 2 秒更新。

Does Rill need administrator rights or special permissions?Rill 需要管理员权限或特殊权限吗？

No. It reads power sensors and battery data that macOS makes available to every app, and per-app energy from your own processes.不需要。它读的是 macOS 向所有应用开放的功率传感器与电池数据，以及你自己进程的能耗。

Can Rill limit charging, for example to 80%?Rill 能限制充电，比如充到 80% 就停吗？

No. Rill only shows what is happening; it never changes how your Mac charges.不能。Rill 只显示正在发生什么，不改变 Mac 的充电方式。

Does Rill free up memory?Rill 能清理内存吗？

It doesn’t run a memory cleaner. When memory runs short, it shows which apps hold a lot of memory but haven’t been used for 30 minutes, so you can quit them. Quitting is what actually frees memory.它不做所谓的内存清理。内存紧张时，它列出占用大、30 分钟没用过的应用，由你决定是否退出。退出才是真正释放内存的办法。

Is Rill free?Rill 免费吗？

Yes. Rill is free and open source under the GPL-3.0.免费，并以 GPL-3.0 协议开源。

Why does macOS say it can’t verify the developer?为什么 macOS 提示无法验证开发者？

Rill isn’t notarized by Apple. Install with the Terminal command to avoid the warning, or open the app once, dismiss the warning, then click Open Anyway in System Settings › Privacy & Security.Rill 没有经过 Apple 公证。用终端命令安装就不会提示；或者先打开一次并关掉提示，再到「系统设置 › 隐私与安全性」点「仍要打开」。

Does Rill send any data?Rill 会上传数据吗？

No. History stays on your Mac for 30 days. Rill goes online only when you choose Check for Updates.不会。历史只存在你的 Mac 上，保留 30 天。只有你点「检查更新」时才联网。
